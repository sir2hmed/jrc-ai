## Training Phases

### Phase 1 — Research, Python & Data Science Foundations
Built the core technical and research workflow:
- **Environment & Version Control:** Python, VS Code, Jupyter Notebook, Conda, Git, and GitHub.
- **Scientific Research:** Paper analysis, reproducibility, ethics, and technical writing (Google Scholar, IEEE Xplore, ACM, arXiv).
- **Python & Data Science:** Core Python programming, EDA, data cleaning, and visualization with NumPy, Pandas, and Matplotlib.

### Phase 2 — Machine Learning Foundations
Covered the end-to-end classical ML pipeline (`Data → Preprocessing → Exploration → Features → Training → Evaluation → Interpretation`) across three tasks:
- **Task 1 — Data Preparation:** Cleaning, encoding, scaling, feature engineering, and EDA.
- **Task 2 — Classical Machine Learning:** Regression, classification, and clustering (Linear/Logistic Regression, Decision Trees, Random Forest, SVM, KNN, Naive Bayes, K-Means).
- **Task 3 — Model Evaluation:** Train/validation/test splits, classification & regression metrics (Accuracy, Precision, Recall, F1, ROC-AUC, MAE, MSE, R²), generalization, and data leakage prevention.

### Phase 3 — Deep Learning with PyTorch
Transitioned to neural networks and deep learning workflows using PyTorch, including computer vision and NLP applications.

### Phase 4 — Advanced AI & Applications
Applied and integrated advanced AI concepts into practical projects.
