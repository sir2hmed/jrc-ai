## Phase 2 — Task 2: Classical Machine Learning

The second task focuses on understanding the main classical machine learning paradigms and algorithms.

### Machine Learning Categories

#### Regression

Used when the model predicts a numerical value.

Examples:

- House price
- Student score
- Sales amount
- Delivery time

#### Classification

Used when the model predicts a category or class.

Examples:

- Fraud / Not Fraud
- Pass / Fail
- Spam / Not Spam
- Disease / No Disease

#### Clustering

Used when no target label is provided and the goal is to discover groups of similar observations.

Examples:

- Customer segmentation
- Behavioral groups
- Product groups
- Similar user profiles

## Algorithms Studied

### 1. Linear Regression

Fits a relationship between input features and a continuous numerical target.

**Typical use:** Regression

### 2. Logistic Regression

Estimates the probability that an observation belongs to a class.

**Typical use:** Classification

### 3. Decision Tree

Makes predictions through a sequence of rule-based decisions.

**Typical use:** Classification and Regression

### 4. Random Forest

Combines predictions from many decision trees to improve robustness and reduce overfitting.

**Typical use:** Classification and Regression

### 5. Support Vector Machine

Finds a decision boundary that separates classes as effectively as possible.

**Typical use:** Classification and Regression

### 6. K-Nearest Neighbors

Makes a prediction using the closest observations in the feature space.

**Typical use:** Classification and Regression

### 7. Naive Bayes

Uses probability and Bayes' theorem to estimate the most likely class.

**Typical use:** Classification

### 8. K-Means

Groups unlabeled observations into clusters based on similarity.

**Typical use:** Clustering

## Phase 2 — Task 3: Model Evaluation

The third task focuses on determining whether a machine learning model performs reliably on unseen data.

### Dataset Splitting

A machine learning workflow normally separates data into:

```text
Dataset
 ├── Training Set   → Used to learn model parameters
 ├── Validation Set → Used to tune and compare choices
 └── Test Set       → Used for final unbiased evaluation
```

The test set should remain unseen until the final evaluation.

---

## Classification Metrics

### Accuracy

Measures the overall proportion of correct predictions.

```text
Accuracy = Correct Predictions / Total Predictions
```

### Precision

Measures how many predicted positive cases were actually positive.

```text
Precision = TP / (TP + FP)
```

High precision is important when false alarms are expensive.

### Recall

Measures how many actual positive cases were successfully detected.

```text
Recall = TP / (TP + FN)
```

High recall is important when missing a positive case is costly.

### F1-Score

Balances Precision and Recall.

```text
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

### ROC-AUC

Measures how well a classifier ranks positive examples above negative examples across different decision thresholds.

---

## Confusion Matrix

A confusion matrix separates classification predictions into:

| | Predicted Positive | Predicted Negative |
|---|---:|---:|
| Actual Positive | True Positive (TP) | False Negative (FN) |
| Actual Negative | False Positive (FP) | True Negative (TN) |

It provides more information than accuracy alone.

---

## Regression Metrics

### Mean Absolute Error — MAE

Measures the average absolute difference between predicted and actual values.

Lower values are better.

### Mean Squared Error — MSE

Squares prediction errors before averaging them.

Large errors therefore receive a stronger penalty.

Lower values are better.

### R² Score

Measures how much of the variation in the target variable is explained by the model.

A score closer to `1.0` generally indicates stronger explanatory performance.

---

## Overfitting and Generalization

### Overfitting

A model is overfitting when it performs very well on training data but performs significantly worse on new data.

Possible approaches for reducing overfitting include:

- More training data
- Simpler models
- Regularization
- Tree pruning
- Cross-validation
- Better feature selection
- Hyperparameter tuning

### Generalization

Generalization describes the ability of a trained model to perform well on new, unseen observations.

The goal is not simply to memorize the training dataset.

---

## Data Leakage

Data leakage occurs when information that should not be available during training accidentally influences the model.

Examples include:

- Fitting preprocessing transformations using the full dataset before splitting.
- Including future information in training features.
- Having duplicate observations across training and testing data.
- Including information directly derived from the target variable.
- Allowing records from the same entity to leak across datasets when entity-level separation is required.

Preventing data leakage is essential for trustworthy model evaluation.
